## Task Summary
The user requested a fix for cursor navigation in the agent list sidebar. The cursor was "jumping" non-linearly instead of following the visual order of items (Session -> Window -> Pane).

## Work Done
- Analyzed tree rendering logic in `src/ui/components/agent_tree.rs`.
- Implemented logical sorting in `src/monitor/task.rs` to order agents by Session, Window (numeric), Window Name, and Pane.
- Synced the projection logic in `src/app/state.rs` (`update_visible_indices`) to use the same sorting criteria.
- Updated `app::state::tests::test_navigation_active_filter_skips_idle` to match the new sorted behavior.
- Updated `CHANGELOG.md` with fix details.
- Verified build, clippy, fmt, and tests.
- Committed changes with a detailed message following the `Problem`/`Solution`/`Changes` format.

## Design Decisions
- **Source-Level Sorting**: Decided to sort the `root_agents` list in the monitor task itself. This ensures that any derived views or filters start from a consistent, logically ordered base.
- **Numeric Window Sorting**: Used `u32` comparison for window indices to ensure window 10 correctly follows window 2, which was previously a point of confusion in alphabetical sorting.

## Challenges & Solutions
| Challenge | Solution |
|-----------|----------|
| Non-linear navigation | Identified that `visible_indices` were populated in discovery order while UI rendered in tree-order. Implemented explicit sorting in `AppState`. |
| Broken unit tests | Updated tests to expect the new sorted order (e.g., sessions starting with 'i' coming before 'w'). |

## Lessons Learned
### Technical Lessons:
- In Ratatui-based TUIs, the selection index must strictly align with the visual traversal order of the widget to provide a predictable user experience.
- Rust's `then_with` is perfect for multi-key sorting of complex structs.

### Process Lessons:
- Always run the full test suite when changing core state management logic, as it often has non-obvious side effects on navigation and filtering.

    let a = &self.agents.root_agents[a_idx];
    let b = &self.agents.root_agents[b_idx];
    a.session.cmp(&b.session)
        .then_with(|| a.window.cmp(&b.window))
