## Task Summary
The user needed to fix the SSH agent definition to use a simple (KISS) approach for state detection, similar to the shell agent. Additionally, there was an issue where the SSH hostname was often displayed as "unknown" in the UI, which required a more robust extraction logic.

## Work Done
- Simplified SSH state detection in `src/config/defaults.toml` by using a basic prompt-based regex.
- Enhanced hostname extraction in `src/parsers/universal.rs` to search through the entire process tree (child and ancestor processes) and fallback to the pane title.
- Added unit tests in `src/parsers/universal.rs` covering nested SSH sessions and title-based extraction.
- Captured and added a new regression test fixture: `tests/fixtures/ssh/case_idle_20260201_093730.txt`.
- Verified changes using `cargo test` and the mandatory `./scripts/reload-test.sh`.
- Committed all changes following the project's commit message convention.

## Design Decisions
- **KISS State Detection**: Switched from complex regex refinements to a simple check for prompt characters (`$`, `#`, `%`, `❯`) at the end of the buffer. This is more robust across different SSH environments.
- **Process Tree Traversal**: Hostname extraction now looks at `child_commands` and `ancestor_commands`. This is necessary because `ssh` is often not the primary process in the pane (e.g., running inside a bash subshell).
- **Title Fallback**: Added a fallback to parse the hostname from the pane title, which often contains `user@host` information even if the command line is obscured.

## Challenges & Solutions
| Challenge | Solution |
|-----------|----------|
| Hostname was "unknown" when ssh ran in subshell | Implemented traversal of `child_commands` and `ancestor_commands` in `agent_display_name`. |
| SSH mux processes had different cmdline formats | Added special handling for processes starting with `ssh: ` and stripping `[mux]` tags. |
| Inconsistent state detection | Applied the same KISS logic used by the generic shell agent. |

## Lessons Learned
### Technical Lessons:
- **Process Ancestry**: In `tmuxx`, detecting agents and their properties often requires looking up and down the process tree (`child_commands`/`ancestor_commands`), not just the immediate pane command.
- **Regex Edge Cases**: Rust's `regex` crate uses `\z` for the very end of the string, which is equivalent to Python's `\Z`.

### Process Lessons:
- **KISS Principle**: Simple prompt detection is often better than complex state-specific regexes for terminal applications.
- **Verification Workflow**: Always run `./scripts/reload-test.sh` and `cargo build --release` before concluding a task in this project.

### To Remember for CLAUDE.md:
- SSH hostname extraction depends on `child_commands` and `ancestor_commands`.
- State detection for interactive shells should remain minimal (prompt-based).
