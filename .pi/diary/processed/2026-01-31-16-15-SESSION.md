## Design Decisions
- **Unified Config**: Added the flag to `CommandConfig` because it's shared between key bindings, menu items, and prompts. This makes the feature available everywhere commands can be executed.
- **Pre-emptive Activation**: Activation happens *before* the command is spawned. This ensures that if the command involves attaching to a session (like `tmux attach`), the correct window is already focused when the attachment occurs.
- **Borrow Checker Avoidance**: Refactored `src/ui/app.rs` to extract `target`, `path`, and `expanded` command into local variables. This avoids holding an immutable borrow of `state` (via `agent`) while calling mutable methods like `state.set_error()`.

## Lessons Learned

### Technical Lessons:
- **State Mutation Patterns**: When using a central `AppState`, always copy/clone small pieces of data (like `target` strings or `path`s) if you need to mutate the state in the same scope.
- **Tmux Command Chaining**: `tmux select-window -t <target>` is the correct way to ensure a specific window is active before a user attaches to the session.
