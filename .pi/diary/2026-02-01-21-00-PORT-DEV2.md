## Task Summary
The goal was to integrate features from a diverged `dev` branch (Global Highlight Rules, External TODOs, Menu Variables) into the current `main` branch. Due to significant history divergence and conflicts, a new branch `dev2` was created from `main`, and features were manually ported, refined, and documented.

## Work Done

- **Ported Features**:

- **Testing**:

## Design Decisions
- **Manual Port vs. Merge**: `dev` was significantly behind `main` (v0.4.6 vs v0.6.0) and had incompatible UI structures. A manual port to `dev2` ensured a clean history and stability.
- **PWD in Border Title**: The user explicitly requested the PWD be "in the top edge of the frame", not as a separate line. Used `ratatui`'s multi-title feature (`block.title(...).title(...)`) to achieve this cleanly.
- **Async External TODO**: Kept the design where `MonitorTask` handles the external command execution to prevent blocking the TUI main loop.

## Mistakes & Corrections

### Where I Made Errors:
- **Initial Porting**: I initially missed adding the `variables` field to the `MenuItem` struct in `src/app/config.rs`, causing compilation errors.
- **UI Interpretation**: I first implemented PWD as a separate `Paragraph` above the box. The user corrected this, specifying it should be *in* the border.
- **Borrow Checker**: I introduced a borrow checker error in `src/ui/app.rs` when trying to access `state.config` while mutating `state`.

### What Caused the Mistakes:
- **Complexity**: Porting a large amount of code manually increases the risk of missing small struct fields.
- **UI Ambiguity**: "Nad spodním boxem" (User's first prompt) vs "v horním okraji rámečku" (User's correction). I interpreted "above" literally as layout placement, not border placement.

## Lessons Learned

### Technical Lessons:
- **Ratatui Titles**: `Block` widgets support multiple titles with different alignments (Left/Right), which is excellent for header bars (e.g., Title on left, Status/Path on right).
- **Manual Ports**: When branches diverge significantly in version/architecture, a manual port is safer and often faster than resolving massive merge conflicts.

### Process Lessons:
- **Verify Compile**: Always run `cargo check` after a large manual port before assuming it's done.
- **UI Precision**: clarify layout requests ("in the border" vs "above the element") before implementing complex layout splits.

### To Remember for CLAUDE.md:
- **Version Divergence**: Be aware that `dev` branches might be experimental and outdated compared to `main`. Always check `CHANGELOG.md` versions first.
